# Proposals for this repository

This repository uses the change-proposal core with `risk-signals`, `verification`, `human-ai-split` and `evidence-verification`. Reviewers on a risk signal: 1. Word cap: one page. Record language: English.

Changes to the practice are recorded here, using the practice. How to contribute: `../../CONTRIBUTING.md`.

## Risk-signal edge cases (grown as met)

| Change | Signal? | Reasoning |
|---|---|---|
| Rewording a rule without changing its requirement level or scope | none | Wording is not a contract; the requirement is. If a reviewer disagrees, record the case here. |
| Adding a label to the label table | contract | Every adopter's template and any future lint depend on the table. |
| Changing a default parameter named in a pattern card | contract | Adopters who took the default inherit the change. |
